¿Cómo funciona?

El ESP32 de Wokwi envía datos por Wi-Fi a la API del servidor. El panel consulta los registros cada 3 segundos.

Los datos mostrados son reales solo cuando llegan a este servidor; puedes usar el botón de prueba para hacer una demostración local.
